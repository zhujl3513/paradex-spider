# Paradex K线数据获取和布林带指标计算

这个程序可以调用Paradex API获取任意交易对的分钟K线数据，并计算布林带指标。

## 功能特性

- 🔄 自动获取Paradex API的K线数据
- 📊 计算布林带指标（上轨、中轨、下轨）
- 📈 提供技术分析信号
- 💾 将结果保存为CSV文件
- 🛡️ 完善的错误处理机制

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 获取K线数据并计算布林带指标

直接运行主程序：

```bash
python main.py
```

程序将自动：
1. 获取可用的交易对列表
2. 选择第一个交易对（默认ETH-USD）
3. 获取过去30天的分钟K线数据
4. 计算20周期布林带指标
5. 分析技术信号
6. 保存结果到CSV文件

### 2. 可视化分析

运行可视化脚本：

```bash
python visualize_bollinger.py
```

这将：
1. 分析布林带信号统计
2. 生成布林带指标图表
3. 保存图表为PNG文件

## 布林带指标说明

布林带由三条线组成：
- **中轨（MA）**：20周期简单移动平均线
- **上轨（Upper Band）**：中轨 + 2倍标准差
- **下轨（Lower Band）**：中轨 - 2倍标准差

## 输出文件

### CSV数据文件
程序会生成一个CSV文件（如：`ETH_USD_bollinger_bands.csv`），包含以下列：
- `timestamp`: 时间戳
- `open`, `high`, `low`, `close`, `volume`: OHLCV数据
- `MA`: 中轨线（移动平均）
- `STD`: 标准差
- `Upper_Band`: 上轨线
- `Lower_Band`: 下轨线
- `BB_Width`: 布林带宽度
- `BB_Position`: 价格在布林带中的位置

### 图表文件
可视化脚本会生成PNG图表文件（如：`ETH_USD_bollinger_chart.png`），包含：
- 价格走势图和布林带区间
- 布林带位置指标图

## 技术信号

程序会分析以下信号：
- 价格触及上轨/下轨（超买/超卖）
- 价格在中轨上方/下方（偏多/偏空）
- 布林带收口/扩张（突破/波动性）

## 自定义参数

可以在代码中修改以下参数：
- `period`: 布林带周期（默认20）
- `std_dev`: 标准差倍数（默认2.0）
- `interval`: 时间间隔（1m, 5m, 15m, 1h, 4h, 1d）
- `limit`: 数据条数限制
